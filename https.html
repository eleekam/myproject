Understanding HTTPS

HTTPS helps protect information sent between your browser and a website from people who might intercept it.

What makes HTTPS different?

HTTPS means Hypertext Transfer Protocol Secure. It uses HTTP over TLS (Transport Layer Security) , a protocol that helps encrypt traffic, verify the server’s identity through certificates, and detect tampering during transmission.

HTTP vs. HTTPS

Differences between HTTP and HTTPS
Feature HTTP HTTPS
Typical URL prefix http:// https://
Protection in transit No TLS encryption TLS encryption
Server identity Not authenticated by HTTP itself Usually verified with a digital certificate
Default port 80 443
Common use today Legacy or special internal uses Recommended for public websites

What happens when HTTPS connects?

  1. Your browser connects to the site's server.
  2. During the TLS handshake, the browser checks the certificate and negotiates connection security.
  3. The browser and server establish encryption keys.
  4. HTTP requests and responses travel through the encrypted connection.

Important: HTTPS protects your connection, but it does not prove a website is trustworthy. Scam and phishing websites can use HTTPS too.
