Understanding HTTP

HTTP is the set of rules that browsers and web servers use to exchange information.

How a request becomes a web page

HTTP stands for Hypertext Transfer Protocol . When you visit a website, your browser (the client) requests a resource such as an HTML page or image. The web server replies with a response, which includes a status code and, often, the requested content.

  1. Enter a URL. The browser identifies the website and resource you want.
  2. Send a request. The browser asks the server for that resource.
  3. Receive a response. The server returns a status code and possibly page content.
  4. Display the result. The browser uses the response to build the page.

Common HTTP methods

Examples of HTTP request methods
Method Typical purpose Example
GET Retrieve information Load a web page
POST Submit data Send a contact form
PUT Replace a resource Update a saved record
DELETE Remove a resource Delete an item through an API

What response codes tell us

Status codes explain how the server handled a request:

  • 200 OK: The request succeeded.
  • 301 Moved Permanently: The resource has a new permanent URL.
  • 404 Not Found: The server cannot find the requested resource.
  • 500 Internal Server Error: The server ran into an unexpected problem.

HTTP is stateless: each request stands on its own. Cookies can help websites maintain a session across requests. HTTP messages can also be cached to avoid downloading unchanged resources repeatedly.
