Seven Key Concepts

Understanding these terms makes it easier to explain how web communication and security work.

01

HTTP

Hypertext Transfer Protocol defines how a client sends a request and how a server returns a response.

02

HTTPS

HTTP carried over a secure TLS connection, protecting data against interception and alteration while in transit.

03

TLS

Transport Layer Security is the modern protocol that establishes authenticated, encrypted connections.

04

SSL

Secure Sockets Layer was an older predecessor to TLS. People still say “SSL certificate,” but modern HTTPS uses TLS.

05

Encryption

The process of converting readable information into protected data that requires the right key to decode.

06

Authentication

A process of checking identity. For HTTPS, the browser uses a certificate chain and other checks to verify the server.

07

Digital Certificate

A signed electronic document that associates a website's identity with a public key and supports TLS verification.

How the concepts connect

HTTP defines the message exchange. TLS provides connection security. Certificates help authenticate the server. Together, HTTP and TLS make HTTPS possible.
