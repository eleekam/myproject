WHAT IS INCLUDED
- quiz.html: quiz page with 10 questions
- quiz.css: styles for quiz page
- quiz.js: countdown, scoring, detailed feedback, reset

HOW TO ADD TO YOUR EXISTING REPOSITORY
1. Open https://github.com/eleekam/myproject
2. Upload quiz.html, quiz.css and quiz.js into the root of the main branch (same folder as index.html).
3. Edit EACH existing HTML page and add this navigation link inside the <nav> element, before </nav>:
   <a href="quiz.html">Quiz</a>
4. Optional but recommended: add a new quiz card to index.html in the .card-grid section:
   <article class="info-card">
     <h3>Test Your Knowledge</h3>
     <p>Take the 10-question HTTP and HTTPS quiz.</p>
     <a href="quiz.html">Start the quiz &rarr;</a>
   </article>
5. Commit changes, then visit your published GitHub Pages website.
6. Test the timer, submit, detailed feedback, reset and navigation.
