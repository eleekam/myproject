Research references

The resources below provide the technical background used to prepare this introductory website.

  1. MDN Web Docs. “An overview of HTTP.” developer.mozilla.org/en-US/docs/Web/HTTP/Overview — Client-server messages and basic HTTP behavior.
  2. MDN Web Docs. “HTTP request methods.” developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Methods — Common methods and their purposes.
  3. MDN Web Docs. “HTTP response status codes.” developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status — Meanings of HTTP response codes.
  4. Cloudflare Learning Center. “What is HTTPS?” cloudflare.com/learning/ssl/what-is-https/ — HTTPS benefits and secure connections.
  5. IETF. “The Transport Layer Security (TLS) Protocol Version 1.3,” RFC 8446. rfc-editor.org/rfc/rfc8446 — Technical specification for TLS 1.3.
